# 🏠 House Analysis

A full-stack house price analysis and prediction web application that helps users explore property data, analyze housing trends, and predict house prices using machine learning.

## 🚀 Features

- 🏠 House price prediction
- 📊 Property price analytics
- 📈 Housing market data visualization
- 🔍 Property details and analysis
- 🤖 Machine learning-based price prediction
- 📋 Property metrics and insights
- 💻 Responsive web interface

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- Recharts

### Backend
- Python
- FastAPI
- Machine Learning
- Scikit-learn

### Machine Learning
- Linear Regression
- Random Forest
- House price dataset
